Dos conexiones diferentes

El gráfico incrustado no admite tu Pine privado ni entrega sus valores al juego. Las señales llegan por alertas de tu cuenta.

Este receptor recoge el estado de Horus al cierre de cada vela de 5 minutos. El movimiento continuo del cerdo necesita además una fuente de cotizaciones.

No se envían órdenes ni se modifican monedas oficiales. El receptor todavía no gobierna la partida.

Conectar tu indicador

  1. Descarga la copia de Horus con salida CrazyPig y ábrela en el editor Pine de tu cuenta TradingView.
  2. Activa «Enviar estado a CrazyPig» y pega la clave del receptor en sus ajustes.
  3. Crea una alerta de «Any alert() function call» con una URL HTTPS pública que termine en /api/horus/webhook. TradingView no puede acceder a localhost.
  4. Comprueba aquí la llegada de señales. Después de cambiar código o ajustes del indicador, recrea la alerta.
